iota
An R7RS-small Scheme interpreter in Haskell

What this is

These pages document iota, an interpreter for the whole of R7RS-small, written in Haskell. Building and installing it is covered in the README. The report itself is at small.r7rs.org.

The documents

  1. Using iota, the user's guide: the command line, data types, control, macros, libraries, the repl and the standard library.
  2. R7RS-small coverage, the coverage table against the report, with the few deviations and extensions listed at the end.
  3. How iota is put together, notes on the inside of the interpreter: the pipeline, the CPS evaluator, hygiene, libraries and numbers.
  4. Hacking on iota, building, testing, where things go, and how to send a change.

cabal haddock builds the API documentation for the Haskell library.

Building the HTML

These pages are published at https://fuzztheplanet.github.io/iota/. To build them yourself you need Emacs. From the top of the repository: 

make -C docs html

Then open docs/index.html. make -C docs clean removes the HTML again. The .org files read fine as plain text and GitHub renders them, so the export is only a nicer way to read them.
