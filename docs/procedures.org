#+TITLE: Libraries and procedures
#+DESCRIPTION: Every name exported by the standard libraries of iota, and a reference for the non-standard (iota extras) library.
#+SETUPFILE: setup.org
#+OPTIONS: num:nil

This page lists every name that each library exports. The
[[#index][index of names]] at the end has all of them in one table: which
libraries export a name, whether it is a procedure or syntax, and
where it is described. Syntax such as =if= and auxiliary syntax such
as =else= are listed with the procedures, because a library exports
them in the same way.

The repl, scripts and =iota eval= start with all of these libraries
imported, so every name here can be used without an =import=. A
=define-library= starts empty and sees only what it imports. The same
goes for an environment made with =(environment ...)=. How =import=
works is described under [[file:guide.org::#libraries][Libraries]] in the
user's guide.

The =(scheme ...)= lists are those of Appendix A of the report with
its errata applied. The one place where iota adds to them is noted
under [[#scheme-r5rs][(scheme r5rs)]]. The [[#iota-extras][(iota extras)]] library is not part
of R7RS-small, and a portable program should not rely on it.

* (iota extras)
  :PROPERTIES:
  :CUSTOM_ID: iota-extras
  :END:

  #+begin_example
    1+ 1- add1 any append-map call-with-output-string compose curry
    displayln every fact fib filter first flip fold foldl foldr id
    iota-range last-pair list-index named-lambda partition port->string
    print reduce remove second string-join string-null? sub1 third
    unfold writeln
  #+end_example

  Conveniences that R7RS-small does not have. The repl, scripts and
  =iota eval= import this library at startup. Anywhere else it has to
  be imported by name:

  #+begin_src scheme
    (import (scheme base) (iota extras))
  #+end_src

  The procedures are defined in Scheme, in =lib/iota/stdlib.iota=.
  =named-lambda= is syntax.

  Some of these names are also used by SRFI 1 and SRFI 13. iota does
  not implement those SRFIs, and where a name coincides the procedure
  here is simpler and sometimes behaves differently:

  - =fold= calls =(f acc x)=. SRFI 1 calls =(f x acc)=.
  - =reduce= is =foldr=, so it works from the right and the initial
    value always takes part. SRFI 1 works from the left and uses the
    initial value only when the list is empty. =(reduce - 0 '(1 2 3 4))=
    is -2 here and 2 in SRFI 1.
  - =unfold= is =(unfold f seed stop?)= and keeps the value that
    stopped it. SRFI 1 has =(unfold stop? mapper successor seed)= and
    drops that value.
  - =any= and =every= return =#t= or =#f=. SRFI 1 returns what the
    predicate returned.
  - =fold=, =any=, =every=, =append-map= and =list-index= take exactly
    one list. SRFI 1 accepts several.
  - =string-join= requires the separator. In SRFI 13 it is optional.
  - =iota-range= takes a count and nothing else. SRFI 1 calls the
    procedure =iota= and accepts a start and a step as well.

  #+begin_src scheme
    (fold cons '() '(1 2 3))                    ; => (((() . 1) . 2) . 3)
    (foldr cons '() '(1 2 3))                   ; => (1 2 3)
    (reduce max 0 '(-5 -3))                     ; => 0
    (any (lambda (x) (and (odd? x) x)) '(2 3))  ; => #t
    (iota-range 5)                              ; => (0 1 2 3 4)
  #+end_src

  With SRFI 1 the first of these would be =(3 2 1)=, the third =-3=
  and the fourth =3=.

** Combinators
   :PROPERTIES:
   :CUSTOM_ID: combinators
   :END:

   - =(id x)= :: Returns =x=.
   - =(flip f)= :: Returns a procedure of two arguments that calls =f=
     with them swapped. =((flip f) a b)= is =(f b a)=.
   - =(curry f a)= :: Returns a procedure of one argument =b= that
     calls =(f a b)=. It fixes the first argument of a two-argument
     procedure and does nothing more general than that.
   - =(compose f g)= :: Returns a procedure of one argument =x= that
     calls =(f (g x))=. It takes exactly two procedures.

   #+begin_src scheme
     ((flip -) 1 10)                ; => 9
     ((curry list 1) 2)             ; => (1 2)
     ((compose car cdr) '(1 2 3))   ; => 2
   #+end_src

** Folds
   :PROPERTIES:
   :CUSTOM_ID: folds
   :END:

   Each of these takes a single list.

   - =(foldl f acc list)= :: Folds from the left. Calls =(f acc x)=
     for each element =x= in order, where =acc= is the result so far,
     and returns the last result. For an empty list it returns =acc=.
   - =(fold f acc list)= :: The same procedure as =foldl=.
   - =(foldr f acc list)= :: Folds from the right. Calls =(f x acc)=
     for each element =x=, starting with the last one. It loops over
     a reversed copy of the list, so a long list does not lead to deep
     recursion.
   - =(reduce f acc list)= :: The same procedure as =foldr=.
   - =(unfold f seed stop?)= :: Returns the list of =seed=,
     =(f seed)=, =(f (f seed))= and so on, up to and including the
     first value for which =stop?= returns true.

   #+begin_src scheme
     (foldl list 0 '(1 2 3))        ; => (((0 1) 2) 3)
     (foldr list 0 '(1 2 3))        ; => (1 (2 (3 0)))
     (unfold (lambda (x) (* x 2)) 1 (lambda (x) (> x 20)))   ; => (1 2 4 8 16 32)
   #+end_src

** Lists
   :PROPERTIES:
   :CUSTOM_ID: lists
   :END:

   - =(filter keep? list)= :: A new list of the elements for which
     =keep?= returns true, in their original order.
   - =(remove drop? list)= :: A new list of the elements for which
     =drop?= returns false.
   - =(partition pred list)= :: Two values, =(filter pred list)= and
     =(remove pred list)=.
   - =(any pred list)= :: =#t= if =pred= returns true for some
     element, otherwise =#f=. It stops at the first such element.
   - =(every pred list)= :: =#t= if =pred= returns true for every
     element, otherwise =#f=. It stops at the first element that
     fails. The result for an empty list is =#t=.
   - =(list-index pred list)= :: The position, counting from zero, of
     the first element for which =pred= returns true, or =#f= if there
     is none.
   - =(append-map f list)= :: Calls =f= on each element and appends
     the lists it returns. The same as =(apply append (map f list))=.
   - =(iota-range n)= :: The list of the integers from 0 up to but not
     including =n=. It is empty when =n= is zero or negative. Other
     Schemes call this =iota=. There is no procedure named =iota=
     here.
   - =(last-pair list)= :: The last pair of a non-empty list. The
     empty list raises an error.
   - =(first list)= :: The same procedure as =car=.
   - =(second list)= :: The same procedure as =cadr=.
   - =(third list)= :: The same procedure as =caddr=.

   #+begin_src scheme
     (partition odd? '(1 2 3 4 5))            ; => (1 3 5) (2 4)
     (list-index even? '(1 3 4 5))            ; => 2
     (append-map (lambda (x) (list x x)) '(1 2 3))   ; => (1 1 2 2 3 3)
     (last-pair '(1 2 3))                     ; => (3)
   #+end_src

** Numbers
   :PROPERTIES:
   :CUSTOM_ID: numbers
   :END:

   - =(add1 n)= :: Returns =(+ n 1)=.
   - =(1+ n)= :: Also returns =(+ n 1)=.
   - =(sub1 n)= :: Returns =(- n 1)=.
   - =(1- n)= :: Also returns =(- n 1)=.
   - =(fact n)= :: The factorial of =n=, as an exact integer of
     whatever size it takes. The result is 1 when =n= is 1 or less.
   - =(fib n)= :: The Fibonacci number with index =n=, where
     =(fib 0)= is 0 and =(fib 1)= is 1. =n= has to be a non-negative
     integer. Given a negative number or a non-integer, the loop
     never ends.

   #+begin_src scheme
     (fact 20)   ; => 2432902008176640000
     (fib 90)    ; => 2880067194370816120
   #+end_src

** Strings and ports
   :PROPERTIES:
   :CUSTOM_ID: strings-and-ports
   :END:

   - =(string-null? string)= :: =#t= if =string= has length zero,
     otherwise =#f=.
   - =(string-join strings separator)= :: Concatenates the strings in
     the list =strings=, with =separator= between each two. The
     separator is required. An empty list gives the empty string.
   - =(call-with-output-string proc)= :: Calls =proc= with a new
     string output port and returns, as a string, everything that was
     written to that port. The value =proc= returns is discarded.
   - =(port->string port)= :: Reads characters from the textual input
     port =port= until the end of file and returns them as a string.
     The port stays open.

   #+begin_src scheme
     (string-join '("a" "b" "c") ", ")                 ; => "a, b, c"
     (call-with-output-string
       (lambda (port) (display "n = " port) (write 42 port)))   ; => "n = 42"
     (port->string (open-input-string "to the end"))   ; => "to the end"
   #+end_src

** Output
   :PROPERTIES:
   :CUSTOM_ID: output
   :END:

   These write to the current output port. None of them takes a port
   argument.

   - =(displayln x)= :: Does =(display x)= and then writes a newline.
   - =(writeln x)= :: Does =(write x)= and then writes a newline.
   - =(print x ...)= :: Does =display= on each argument in order,
     with nothing between them, and then writes a newline.

** Syntax
   :PROPERTIES:
   :CUSTOM_ID: syntax
   :END:

   - =(named-lambda (name formal ...) body ...)= :: Like
     =(lambda (formal ...) body ...)=, except that the procedure
     carries =name=. It prints as =#<procedure name>= and an arity
     error mentions =name=. A rest parameter is written as in
     =lambda=, for example =(named-lambda (name . args) body ...)=.
     =name= is not bound inside the body, so the procedure cannot
     call itself through it. =(define (name formal ...) body ...)=
     expands into this form.

   #+begin_src scheme
     ((named-lambda (double x) (* x 2)) 4)   ; => 8
     (named-lambda (double x) (* x 2))       ; => #<procedure double>
   #+end_src

** Extensions that are not in a library
   :PROPERTIES:
   :CUSTOM_ID: extensions-that-are-not-in-a-library
   :END:

   A few extensions are part of the reader or of the core syntax, so
   no library exports them: square brackets as parentheses, the
   curried form of =define=, =(define x)= without a value, =eval=
   with one argument and =force= on a value that is not a promise.
   They are listed under [[file:r7rs-coverage.org::#deviations-and-extensions][Deviations and extensions]]
   on the coverage page.
