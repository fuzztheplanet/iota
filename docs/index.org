These pages document [[https://github.com/fuzztheplanet/iota][iota]], an interpreter for R7RS-small, written
in Haskell. It is Linux only. Building and installing it is covered in
[[file:install.org][Installing iota]]. The report itself is at [[https://small.r7rs.org/][small.r7rs.org]].

*Disclaimer:* /iota/ was initially written while following the tutorials [[https://en.wikibooks.org/wiki/Write_Yourself_a_Scheme_in_48_Hours][Write
Yourself a Scheme in 48 Hours]] and [[https://www.wespiser.com/writings/wyas/home.html][Version 2]]. I left the code unpublished for
years and now I revamped it with AI. So most of the source code and
documentation that you will see has been generated by AI.

The following documents could be of interest:

1. [[file:install.org][Installing iota]], the toolchain, building, testing and installing, and
   what the executable needs at run time.
2. [[file:tutorial.org][A tour of iota]], a tutorial with examples to type in.
3. [[file:examples.org][Examples]], the example programs, each with what it prints.
4. [[file:guide.org][Using iota]], the user's guide: the command line, the repl, data types,
   control, macros, libraries, errors, limits and using iota from a
   Haskell program.
5. [[file:procedures.org][Libraries and procedures]], what each library exports, an index of
   every name, and the reference for the non-standard =(iota extras)=.
6. [[file:r7rs-coverage.org][R7RS-small coverage]], the coverage table against the report, the result
   of an external test suite, and the known defects, deviations and
   extensions.
7. [[file:architecture.org][How iota is put together]], notes on the inside of the interpreter: the
   pipeline, the CPS evaluator, hygiene, libraries and numbers.
8. [[file:hacking.org][Hacking on iota]], building, testing, where things go, and how to send a
   change.
9. [[file:api/index.html][API documentation]] for the Haskell library, generated by Haddock.
