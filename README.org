#+TITLE: iota

An R7RS-small Scheme interpreter written in Haskell.

* About

/iota/ implements [[https://small.r7rs.org/][R7RS-small]]: exact rationals and complex numbers, hygienic
=syntax-rules=, re-entrant continuations with a correct =dynamic-wind=, the
full exception system and real libraries. It runs scripts and has a readline
style /repl/. It is not complete to the letter. The [[https://fuzztheplanet.github.io/iota/r7rs-coverage.html][coverage page]] compares it
with the report feature by feature, says how it does on an external R7RS test
suite, and lists the known defects, the deviations and the extensions.

*Disclaimer:* /iota/ was initially written while following the tutorials [[https://en.wikibooks.org/wiki/Write_Yourself_a_Scheme_in_48_Hours][Write
Yourself a Scheme in 48 Hours]] and [[https://www.wespiser.com/writings/wyas/home.html][Version 2]]. I left the code unpublished for
years and now I revamped it with AI. So most of the source code and
documentation that you will see has been generated by AI.

Things I read while writing it:

* Building

iota is built from source with =make=. Linux only. You need GHC, cabal
and GNU make. The documentation also needs Emacs, and the external test
suite needs curl.

#+begin_src sh
git clone https://github.com/fuzztheplanet/iota.git
cd iota
make build      # compile the library and the iota executable
make test       # run the test suites
make install    # install the iota executable; cabal reports where it put it
#+end_src

=make= on its own does =build=, =test= and =docs=. Every step has a target:

| Target             | What it does                                                         |
|--------------------+----------------------------------------------------------------------|
| =make build=       | compile the library and the =iota= executable                        |
| =make test=        | build, then run the two test suites                                  |
| =make install=     | install the =iota= executable into cabal's install directory         |
| =make docs=        | build the documentation site under =docs/=, pages and API reference  |
| =make api=         | build only the API reference, into =docs/api/=                       |
| =make conformance= | run the external R7RS test suite, which is downloaded the first time |
| =make check=       | the full check: warnings are errors, both test suites, the API reference and the external suite |
| =make dist=        | check that the source distribution builds and passes on its own      |
| =make clean=       | remove everything the targets above built                            |
| =make help=        | list the targets and the variables                                   |

The Makefile runs cabal for the Haskell side and Emacs for the pages.
=CABALFLAGS= is passed on to cabal, as in ~make build CABALFLAGS=-j4~, and
~make install INSTALLFLAGS=--installdir=$HOME/bin~ chooses where the
executable goes. After =make docs=, open =docs/index.html=.

The site that =make docs= builds is not kept in the repository. The
continuous integration workflow in =.github/workflows/ci.yml= runs
=make check= and =make docs= on every push and pull request, and on
=main= it publishes the site that =make docs= built.

[[https://fuzztheplanet.github.io/iota/install.html][Installing iota]] has the prerequisites in detail, the extra cabal settings
that Arch Linux needs, where the executable ends up and what it needs at run
time, and what to do when a step fails.

* Usage

#+begin_src sh
iota                     # start the repl
iota FILE.iota [ARG...]  # run a script. ARGs are visible in (command-line)
iota run FILE.iota       # run a script, as an explicit subcommand
iota eval '(+ 1 2)'      # evaluate an expression and print the result
iota --version
iota --help
#+end_src

A session looks like this:

#+begin_example
    $ iota
    iota, an R7RS-small Scheme. Type :help for help.
    iota> (define (fact n) (if (= n 0) 1 (* n (fact (- n 1)))))
    iota> (fact 30)
    265252859812191058636308480000000
    iota> (sqrt -4)
    +2i
    iota> (call/cc (lambda (k) (+ 1 (k 42))))
    42
#+end_example

The repl completes bound names on tab, keeps a history, continues an
unbalanced line on the next one and has a few =:= commands. =:help= lists
them. Scripts and the repl start with every standard library imported, so you
can type =(display "hi")= without an =import= first. A portable program should
still say =(import (scheme base))= at the top.

Library files end in =.iota=: =(import (my lib))= looks for =my/lib.iota=.
Where it looks, and everything else about the command line, the repl and
libraries, is in the [[https://fuzztheplanet.github.io/iota/guide.html][user's guide]].

The =examples/= directory has small programs, listed in [[file:examples/README.org][examples/README.org]]
and shown with their output on the [[https://fuzztheplanet.github.io/iota/examples.html][examples page]].
=iota examples/NAME.iota= runs one of them from the top of the repository.

  - [[https://fuzztheplanet.github.io/iota/install.html][Installing iota]]: the toolchain, building, testing and installing.

front page. =make docs= builds the HTML from them. Changes between versions
are listed in [[file:CHANGELOG.org][CHANGELOG.org]].
